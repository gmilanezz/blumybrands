# Blummy Brands — Angular

Projeto adaptado da estrutura da Lala Store VIP para a identidade visual Blummy Brands.

## Rodar localmente

```bash
npm install
npm start
```

O Angular CLI abrirá a aplicação no navegador (normalmente em http://localhost:4200).

## Build de produção

```bash
npm run build
```

## Identidade visual

- Fundo principal: `#080808`
- Dourado principal: `#D4AF37`
- Dourado claro: `#E7C766`
- Dourado escuro: `#B88A28`

A logo está em `public./assets/index/logo-blummy.png`.

Observação: o mock mantém o catálogo de produtos/coleções que veio no projeto-base. Como o ZIP original não continha os arquivos de fotos dos produtos, imagens ausentes usam um placeholder da Blummy Brands.

## Antes de publicar

Os links de WhatsApp, Instagram e e-mail foram deixados sem destino para não reutilizar os contatos da loja anterior. Configure os contatos oficiais da Blummy Brands no footer, no botão flutuante e no checkout antes de publicar.
